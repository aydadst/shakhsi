# Responsive Sample Website (Bootstrap + Custom CSS)

این پروژه یک وب‌سایت نمونه است که با هدف نمایش مهارت در طراحی ریسپانسیو توسعه داده شده.  
ساختار اصلی UI با Bootstrap اجرا شده و برای پوشش محدودیت‌ها و شخصی‌سازی‌های مورد نیاز، از CSS اختصاصی نیز استفاده شده است.

---

## ویژگی‌ها

- کاملاً ریسپانسیو روی موبایل، تبلت و دسکتاپ
- استفاده از Bootstrap برای Grid و کمپوننت‌ها
- شخصی‌سازی استایل با CSS سفارشی
- ساختار ماژولار و قابل توسعه

---

## تکنولوژی‌ها

- HTML5
- CSS3 (Custom)
- Bootstrap 5

---

## هدف پروژه

این پروژه صرفاً به عنوان نمونه کار برای نمایش توانایی در طراحی ریسپانسیو و کار با Bootstrap توسعه یافته و جنبه عملی سفارش مشتری ندارد.
